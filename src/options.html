02 / Model

总结模型

局域网 New API 接入要点。

1. Base URL 填 New API 服务器地址，例如 http://192.168.1.10:3000/v1（默认端口 3000，按实际部署调整）。

2. API Key 填 New API 后台「令牌」页创建的令牌（sk-…），注意令牌的分组和额度。

3. 模型名必须是该令牌可用模型，点「拉取模型列表」可自动获取。

4. 若报 401 检查令牌；报无法连接则确认本机与服务器同处一个局域网、防火墙已放行端口。

04 / Shortcuts

快捷键

默认：保存划线 ⌘⇧O，总结整页 ⌘⇧P，总结划线 ⌘⇧K（Windows 把 ⌘ 换成 Ctrl）。点「重录」可反复设置；点「复位」回到默认。改完后请保存。Chrome 命令快捷键也可在 chrome://extensions/shortcuts 中改。页面没有划线时，保存/总结划线的快捷键会自动改用剪贴板内容，剪贴板无需独立快捷键。

05 / Setup

接入说明

  1. 在飞书开放平台创建企业自建应用，开通 docx:document、docx:document.block:convert；若文档是 wiki 链接，再开通 wiki 读权限。
  2. 发布应用版本，并把目标云文档「分享」给该应用（添加文档协作者）。
  3. 把 App ID、App Secret 和文档链接填到本页，点「测试连接」。
  4. 配置任意兼容 OpenAI 的模型后，即可保存划线、总结划线或总结网页。
