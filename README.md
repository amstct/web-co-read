# XQcoread

Chrome 插件：在网页上划线保存原文，总结当前划线，或把整页/指定链接总结后，**增量写入**指定飞书云文档末尾。

## 功能

1. **划线保存**：选中网页句子后按下快捷键（默认 `⌘⇧O` / `Ctrl+Shift+O`），原文追加到飞书文档。
2. **划线总结**：选中文字后按下快捷键（默认 `⌘⇧K` / `Ctrl+Shift+K`），提炼后再追加到同一文档。
3. **页面总结**：在当前标签页按快捷键（默认 `⌘⇧P` / `Ctrl+Shift+P`），或在弹窗粘贴 URL，提炼后再追加到同一文档。
4. **剪贴板保存**：复制任意内容后按快捷键（默认 `⌘⇧X` / `Ctrl+Shift+X`），原文追加到飞书文档。
5. **剪贴板总结**：复制任意内容后按快捷键（默认 `⌘⇧L` / `Ctrl+Shift+L`，无 Chrome 级默认键，可在 `chrome://extensions/shortcuts` 或设置页配置），提炼后再追加到同一文档。
6. **可配置快捷键**、**飞书文档链接**、**整页/划线总结提示词**。
7. 独立 **Settings** 页，浅色科技风界面。

## 安装

1. 打开 Chrome，访问 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库根目录
4. 点击工具栏图标进入弹窗，或右键扩展选择「选项」完成配置

## 飞书配置

1. 打开 [飞书开放平台](https://open.feishu.cn/app) 创建企业自建应用
2. 开通权限：
   - `docx:document`（或可编辑云文档）
   - `docx:document.block:convert`
   - 若目标是 Wiki 链接，再开通 wiki 相关读权限
3. 创建并发布一个应用版本，拿到 **App ID** / **App Secret**
4. 打开目标飞书文档，分享给该应用（把应用加为文档协作者）
5. 把文档链接、App ID、App Secret 填进插件设置，点「测试连接」

国内飞书 API 默认 `https://open.feishu.cn`；国际版 Lark 请在设置中切换。

## 总结模型

页面总结走兼容 OpenAI `chat/completions` 的接口，默认从局域网 **New API** 网关接入：

1. Base URL 填 New API 服务器地址，例如 `http://<服务器IP>:3000/v1`（默认端口 3000，按实际部署调整）
2. API Key 填 New API 后台「令牌」页创建的令牌（`sk-…`），注意令牌的分组和额度
3. 模型名必须是该令牌可用的模型，设置页切到「New API（局域网）」后点「拉取模型列表」即可自动获取（走 `GET /v1/models`）

其他 OpenAI 兼容服务同样可用：OpenAI `https://api.openai.com/v1`、DeepSeek `https://api.deepseek.com/v1`、其他代理或国产方舟，按厂商文档填写 Base URL、模型名和 API Key。

**思考模型（Qwen3 等）**：总结不需要推理链，插件默认在请求里带 `enable_thinking=false`（兼容 vLLM 的 `chat_template_kwargs` 与 DashScope 的顶层写法），并在响应端剥离 `<think>` 残留，避免思考过程混入摘要、拖慢生成。普通模型会忽略该参数；若你的网关严格校验未知字段报 400，可在设置里关掉「禁用模型思考」。


排错提示：

- **401 / 令牌无效**：检查令牌是否正确、额度是否用完、分组是否包含所选模型
- **无法连接**：确认浏览器所在机器与 New API 服务器在同一局域网，且防火墙放行了端口
- **CORS / 403**：若 New API 前面有反向代理，确认放行了 `chrome-extension://` 来源的跨域请求

## 使用

- 划选文本 → `⌘⇧O`（可改）→ 原文写入文档末尾
- 划选文本 → `⌘⇧K`（可改）→ 划线摘要写入文档末尾
- 任意网页 → `⌘⇧P`（可改）→ 整页摘要写入文档末尾
- 复制任意内容（网页、聊天记录、笔记等）→ `⌘⇧X`（可改）→ 剪贴板原文写入文档末尾
- 复制任意内容 → `⌘⇧L`（可改）→ 剪贴板摘要写入文档末尾
- 弹窗可总结当前页、总结当前划线、保存/总结剪贴板，或粘贴任意 http/https 链接
- 快捷键也可在 `chrome://extensions/shortcuts` 中修改扩展命令

剪贴板读取通过 offscreen 文档完成（需 `clipboardRead` 权限），不依赖页面焦点；复制的内容统一截断到 25 万字符以内。

## 权限说明

插件需要访问当前网页正文、调用飞书开放接口和模型接口。App Secret 与 API Key 只保存在浏览器本地 `chrome.storage.local`，不会上传到本项目服务器。
