02 / Model

总结模型

Ollama 被 Chrome 插件访问时必须放开来源，否则会 403。

1. 终端执行：launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"

2. 菜单栏 Ollama → Quit Ollama，再重新打开。

3. 模型名必须和 ollama list 完全一致。

4. 上下文长度要和 Ollama 一致（128K = 131072）。改大后执行 ollama stop 模型名，让模型按新窗口重新加载。

04 / Shortcuts

快捷键

默认：划线 ⌘⇧O（Windows 为 Ctrl+Shift+O），总结 ⌘⇧P。点「重录」可反复设置；点「复位」回到默认。改完后请保存。

05 / Setup

接入说明

  1. 在飞书开放平台创建企业自建应用，开通 docx:document、docx:document.block:convert；若文档是 wiki 链接，再开通 wiki 读权限。
  2. 发布应用版本，并把目标云文档「分享」给该应用（添加文档协作者）。
  3. 把 App ID、App Secret 和文档链接填到本页，点「测试连接」。
  4. 配置任意兼容 OpenAI 的模型后，即可划线保存或总结网页。
